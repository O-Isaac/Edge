### Frequently Asked Questions

<Collapse title="How to make the Stamina/Health bars colored?" open>
  Rename hudmenu colored.swf to hudmenu.swf (either rename the original file or
  delete it beforehand)
</Collapse>

<Collapse title="How to set bars to top left position?" open>
  Rename skyhud - top playerbars.txt to skyhud.txt (either rename the original
  file or delete it beforehand)
</Collapse>

<Collapse title="How to get the CSM Tweenmenu?" open>
  Rename Tweenmenu CSM.swf to tweenmenu.swf
</Collapse>

<Collapse title="How to get the left-sided Sleep/Wait menu?" open>
  Rename sleepwaitmenu - left sided.swf to sleepwaitmenu.swf
</Collapse>

<Collapse title="How to get the 21:9 Favorites menu?" open>
  Rename favoritesmenu 21-9.swf to favoritesmenu.swf (either rename the original
  file or delete it beforehand)
</Collapse>

<Collapse title="MoreHUD preset is not working" open> 
  <Steps>
    1. Uninstall moreHUD via MCM 
    2. Load save without moreHUD esp active 
    3. Re-enabling moreHUD and load EdgeUI preset via MCM.
  </Steps>
</Collapse>
